Time Series Analysis Using Python

Project Description

This project analyses monthly airline passenger data using Python and time series analysis techniques.

Dataset

Airline Passengers dataset (1949–1960), containing 144 monthly observations.

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Statsmodels
* Scikit-learn

Practical Programs

1. Datetime Conversion
2. Time Series Visualization
3. Trend Analysis
4. Seasonality Analysis
5. Stationarity Analysis
6. ADF Test
7. Differencing
8. Moving Average and EWMA
9. Time Series Decomposition
10. ACF and PACF
11. ARIMA Forecasting
12. Simple Exponential Smoothing
13. Holt-Winters Forecasting

Project Outputs

* Time series graphs
* Forecast results in CSV format
* Project report in PDF format

How to Run

Install the required libraries:

pip install pandas numpy matplotlib seaborn statsmodels scikit-learn openpyxl

Run a practical program:

python src/02_time_series_visualization.py
